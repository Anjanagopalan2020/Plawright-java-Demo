# Playwright Java Demo
 
This project demonstrates UI automation using Playwright with Java.
 
## Technologies Used
 
- Java
- Playwright
- Maven
- TestNG
 
## Project Structure
 
```
src
├── main
└── test
├── java
└── resources
```
 
## Prerequisites
 
- Java 17+
- Maven
- IDE (IntelliJ/Eclipse)
 
## Installation
 
Clone the repository:
 
```bash
git clone https://github.com/Anjanagopalan2020/Plawright-java-Demo.git
```
 
Navigate to the project:
 
```bash
cd Plawright-java-Demo
```
 
Install dependencies:
 
```bash
mvn clean install
```
 
## Run Tests
 
```bash
mvn test
```
 
## Features Covered
 
- Locators
- Assertions
- Frames
- Windows/Tabs Handling
- Alerts
- File Upload
- Mouse Hover
- Dropdowns
